# 🐍 贪吃蛇 V2 - 抖音小游戏版

康泰园主题贪吃蛇游戏，支持抖音小程序运行。

## ✨ V2 新特性

### 🎮 操作改进
- ✅ **方向键控制** - 页面底部有上下左右四个按钮
- ✅ **滑动支持** - 仍然支持滑动手势控制
- ✅ **操作更简单** - 不再需要精确滑动，点击按钮即可

### 🌈 蛇颜色进化系统
蛇每吃10个食物就会进化，颜色变化：

| 吃的数量 | 形态名称 | 颜色 |
|---------|---------|------|
| 0+ | 小青蛇 | 🟢 绿色 |
| 10+ | 蓝蛇 | 🔵 蓝色 |
| 20+ | 紫蛇 | 🟣 紫色 |
| 35+ | 金蛇 | 🟠 橙色 |
| 50+ | 玫瑰蛇 | 💗 粉色 |
| 70+ | 火焰蛇 | 🔴 红色 |
| 100+ | 金龙蛇 | 🌟 金色发光 |

### 🎨 视觉改进
- 蛇头有眼睛，会根据方向转动
- 蛇身有花纹
- 进化时边框颜色变化
- 金龙蛇有发光效果

## 🚀 使用方法

### 方法一：抖音开发者工具

1. 下载 [抖音开发者工具](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/developer-tool/download/developer-tool-update-and-download)
2. 打开开发者工具
3. 选择「小游戏」项目
4. 导入本项目文件夹 `snake-douyin`
5. 点击「编译」预览游戏
6. 点击「预览」生成二维码，用抖音扫码体验

### 方法二：直接上传

1. 在抖音开发者工具中打开项目
2. 点击「上传」按钮
3. 填写版本号和说明
4. 在抖音开放平台提交审核

## 🎮 玩法说明

- **滑动屏幕**控制蛇的移动方向
- **吃食物**获得分数（每个10分）
- **撞墙或撞自己**游戏结束
- 分数越高，蛇移动越快

## 🔧 自定义修改

### 修改颜色

在 `game.js` 中找到 `CONFIG.colors` 修改：

```javascript
colors: {
  bg: '#1a1a2e',      // 背景色
  snake: '#00ff88',   // 蛇身颜色
  snakeHead: '#00ffcc', // 蛇头颜色
  food: '#ff6b6b',    // 食物颜色
  text: '#ffffff',    // 文字颜色
  score: '#ffd93d'    // 分数颜色
}
```

### 修改速度

```javascript
speed: 150,  // 初始速度（毫秒），数值越小越快
```

### 修改格子大小

```javascript
gridSize: 20,  // 每个格子的大小（像素）
```
